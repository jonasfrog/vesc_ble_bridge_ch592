# vesc_ble_bridge_ch592

replacement for the nrf51 or esp32-c3 vesc ble bridge using the ch592


FLASHING:
the hex file can be found under obj folder, or you can compile using mounriverstudio
flashing can be done over usb connection using wchisp studio or wchisp project


pin connections
PA4 (CH592 RX3) <--- VESC TX

PA5 (CH592 TX3) ---> VESC RX

GND --- GND
